## Evidence Class Legend & Non-Substitution Rules (`VER-07.3..6`, `H6`)

| Evidence Class | Meaning | Substitution / Acceptance Boundary |
|---|---|---|
| `headless-tested` | Verified via deterministic `.NET 11` unit/replay/contract tests (`ProjectAegis.*.Tests`) | Cannot substitute for `Editor-PlayMode` or `owner-only` walk |
| `proxy-tested` | Verified via `PlayModeSmokeHarnessTests` or `UnityAdapter` projection/bridge harness | Cannot substitute for live Unity `:8081` visual/input PlayMode |
| `fixture-only` | Exercised against synthetic or injected harness sources (`CombatVerticalSliceHarness` / scripted sources) | Must never be reported as live scenario composition proof |
| `Editor-PlayMode` | Executed inside live Unity Editor (`:8081`) with `ProjectAegis.Unity.Tests` + screenshot inspection | Scheduled for Track B (`M4`: `DRG-235` / `DRG-177`); `pending-M4-PlayMode` at M1 exit |
| `owner-only` | Requires explicit human owner decision (`DRG-244` / `VER-07.4`), separate from CI green | Always `Pending` until owner signs the current revision SHA |
| `unverified` | Transition, bridge wiring, or explanation surface not yet proven or intentionally fail-closed | Flagged explicitly in Section 2; never silently marked green |

## Section 3 — Slice Exit Gate Review Protocol (`DRG-193`, `DRG-201`, `DRG-244`)

1. **`DRG-201` (M1 / M3 Evidence Ledger Consumption):** Every headless/gauntlet verification run emitting `EvidenceLedger` records (`src/ProjectAegis.Data/Evidence/EvidenceLedger.cs`) maps observations into the six typed categories (`Contact`, `Authority`, `DataLink`, `Recommendation`, `Engagement`, `Assessment`) and attaches a `RevisionBoundAcceptanceRecord` with `OwnerAcceptanceStatus.Pending` and explicit `AcceptanceEvidenceLayer`.
2. **`DRG-193` (M2 IFC Mission-Thread Consumption):** Integrated Fire Control verification exercises normal, degraded-link, lost-node, conflicting-allocation, and authority-withheld transitions across Section 1 stages (`Find -> Fix -> Track -> Target -> Engage -> Assess`) and updates or clears `KCM-GAP-02` / `KCM-GAP-03` evidence rows without erasing remaining gaps.
3. **`DRG-235` / `DRG-177` (M4 Live Unity `:8081` PlayMode Consumption):** Track B PlayMode verification updates `pending-M4-PlayMode` rows to `Editor-PlayMode` only after live `:8081` tests (`> 61` passed, `0` Console errors) and visually inspected Game View screenshots are archived under `production/qa/evidence/sprint-6/`.
4. **`DRG-244` (M5 Owner Acceptance Pack Consumption):** Final owner acceptance pack references this matrix, distinguishes `headless-tested` / `proxy-tested` / `fixture-only` / `Editor-PlayMode` / `owner-only` evidence classes, retains `DRG-208` (`9cd872c7`) as historical-only, and lists all 5 untouched `hold:owner-go` issues (`DRG-268`, `DRG-269`, `DRG-236`, `DRG-231`, `DRG-347`).
