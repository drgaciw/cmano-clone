02 / What changed

Targeted correctness fixes and reviewed cleanup

Rollback restores the captured document

Deep undo snapshots replace shallow capture. Known snapshot IDs restore the full captured state; unknown IDs report failure without mutation. Regression tests pin both paths.

More precise exception behavior

Adjudication diff guards now identify the correct null parameter, before or after. Hindsight request ownership now ensures disposal when request-content creation throws.

Contracts and side effects preserved

Cast and switch cleanup preserves existing results. Unused-code removal retains side-effecting calls and public DTO contracts. Intentional defaults and boundary guards remain explicit.

Nullability matches actual producers

Non-null return annotations were strengthened where every path returns an object; eleven redundant caller null-forgiving operators were removed. Shared nullable paths remain nullable.

Repeatable analyzer execution

The wrapper pins the CLI and SDK, builds first, inspects all frameworks with solution-wide analysis, and disables personal/global settings layers. Findings are matched by identity and multiplicity.

A regression gate that fails safely

The gate rejects malformed or failed reports, new findings, and ambiguous mixed-disposition matches. It validates audit fields and framework tags without silently regenerating the baseline.

Remediation scope: 606 changed source files. Final behavior/contract review and the Unity/C# architecture checklist both passed.
